# ROADMAP — MediaMaid

> **Phase 2 of the side-hustle year (Feb – Apr 2027). Starts only if the Phase 1 gate is green.**
> Master plan lives in the home repo: side-hustle-master-plan.md

**One-liner:** the modern one-time-priced media organizer — a FileBot alternative that respects you.

**Why now:** FileBot's beloved $20 lifetime license is gone; it is now $8/year or $80 lifetime
($79.99 one-off in the app stores), and "FileBot alternative" is a standing content genre.
The gap: a fast, friendly, lifetime-priced organizer. That is this product.

**Positioning:** the Stream Deck plugin stays free and open source forever — it is the marketing funnel.
The standalone desktop app is the paid product.

## Rules

Same as the master plan: desktop app = zero marginal cost (runs on the user's machine),
AI for development only, lifetime pricing, free plugin forever, ≤ 2 hrs/week maintenance.

## Quarter plan

**Month 1 (Feb 2027)**
- [ ] Plugin v2: dry-run preview hardening, per-standard settings
- [ ] Extract the rename engine into a standalone desktop app (Windows/macOS/Linux)

**Month 2 (Mar 2027)**
- [ ] Watch folders: auto-organize on drop
- [ ] Full undo journal — every rename reversible, logged locally

**Month 3 (Apr 2027)**
- [ ] Pro tier: transcode/reformat pipeline — offline batch jobs on the user's machine, never runtime AI
- [ ] Launch at $19 lifetime (founding) → $29; same storefront as IA Helper
- [ ] Cross-promo: r/DataHoarder, r/jellyfin, r/PleX + the IA Helper install base and email list

## Pricing sketch

| Tier | Price | Includes |
|---|---|---|
| Plugin (Stream Deck) | Free forever | quick rename, smart fix |
| App — Free | $0 | single-folder renames, all standards |
| App — Pro | $19 founding → $29 | watch folders, undo journal, transcode pipeline |

## Gate criteria (end of Apr 2027)

- **Green (≥ 25 lifetime sales):** proceed to Phase 3 (FrictionPoint) in May.
- **Yellow/Red:** pause new products; iterate here or return to IA Helper.
